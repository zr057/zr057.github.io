FollowMe Autonomous Shopping Cart

A two-stage indoor robotics project that progressed from an exploratory green-cart conversion to a completed four-wheel experimental platform for indoor planning, tracking, and obstacle-avoidance validation.

View GitHub repository

Project outcome

The project developed through two physical platforms: an early green-cart prototype for mechanical and sensor integration, followed by a dedicated four-wheel vehicle for final planning, trajectory-tracking, and corridor obstacle-avoidance experiments.

  • Completed early LiDAR, wiring, and drive-layout integration on the green cart.
  • Completed a four-wheel experimental platform with onboard computing, operator display, and front-mounted LiDAR.
  • Implemented grid-based global planning and local obstacle avoidance.
  • Connected planning output with closed-loop chassis control and validated the system in an indoor corridor.

Platform development

Early hardware integration

The green cart served as the first physical integration platform for LiDAR placement, wiring, and drive installation. Experience from this stage informed the completed four-wheel vehicle used in the final experiments.

Final experimental platform

The completed system used a dedicated four-wheel mechanical vehicle

The final platform combined a rigid mobile chassis, front-mounted 2D LiDAR, onboard computing, and an integrated display and control interface. This configuration provided a consistent base for indoor route execution, trajectory tracking, and obstacle-avoidance experiments.

System workflow

From environment representation to chassis motion

The verified planning workflow connects sensor inputs, occupancy-grid representation, global-local planning, and closed-loop control.

Sense

LiDAR and odometry capture the surrounding geometry and robot state.

03

Original proposal · Intended scope

Proposed technical roadmap

The initial proposal organized the project into four connected workstreams:

  • Platform integration: mobile-base selection, motor control, LiDAR placement, and sensor layout.
  • Autonomous motion: A* global planning, local obstacle avoidance, and PID path tracking.
  • Perception concepts: environment mapping, visual perception, and voice interaction.
  • Validation: system integration followed by simulation and physical experiments.

This roadmap records the intended project scope; it is not evidence that every proposed module reached final integration.

Planning contribution

  • Eight-direction grid search with map-boundary and collision checks
  • Heuristic-guided node expansion and parent-based path reconstruction
  • Redundant-turn removal and collision-checked path shortcutting
  • Local trajectory scoring using goal direction, obstacle clearance, speed, and global-route consistency
