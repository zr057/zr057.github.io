Project overview

From a shopping-cart prototype to an integrated robotic system

This project explored how sensing, planning, and motion control could be integrated into an autonomous shopping-cart system. The work began with the conversion of a conventional folding cart, including motorized drive installation, LiDAR mounting, embedded control, onboard computing, and ROS communication.

The complete software workflow was subsequently deployed on a dedicated Ackermann-steering mobile platform. The integrated system combined LiDAR–IMU mapping, robot localization, UWB target positioning, global-local path planning, closed-loop motion control, and physical experiment validation.

Planning algorithms

Global efficiency and local responsiveness

The planning stack combined an improved A* global planner with an adaptive DWA local planner.

Improved A* global planning

The global planner introduced target-oriented direction screening, obstacle-density-based heuristic adjustment, and two-stage redundant-node removal. These changes reduced unnecessary exploration and generated smoother routes with fewer turns.

  • Direction screening retained five target-oriented search directions.
  • Obstacle density adjusted the heuristic contribution.
  • Collinear-node removal and collision-checked shortcutting simplified the route.

Improved DWA local planning

The local planner added a target-distance term and dynamically adjusted obstacle-avoidance weights. In open space, it prioritized efficient forward motion. Near an obstacle, safety and clearance received greater weight.

Physical validation

Localization, navigation, following, and avoidance

The final evaluation combined repeated measurements with physical indoor experiments.

UWB trajectory filtering

Three walking routes were tested three times each, producing nine measured target trajectories.

  • MSE: 0.0143 m²
  • MAE: 0.0938 m
  • Maximum deviation: 0.2847 m
  • Trajectory roughness: 0.0384 → 0.0100 m

Repeated navigation

The robot completed ten navigation trials between fixed start and target positions.

  • Travel-distance error: 0.15 ± 0.07%
  • Mean lateral offset: 0.012 ± 0.012 m
  • Mean heading deviation: 1.9 ± 1.0°
  • Heading fluctuation: 1.7 ± 0.4°

Target following

The robot followed a moving target along a route containing straight and turning segments. The mean following distance was 1.39 m, within the intended 1.0–1.5 m interval. Temporary fluctuations appeared during turns, after which the system returned to a stable following state.

Dynamic obstacle avoidance

A pedestrian entered the planned route while static obstacles remained present. The robot generated a collision-free detour, maintained target tracking, and continued the following task after passing the obstacle.

Engineering lessons

Algorithms depend on the complete system

The project demonstrated that autonomous robot performance depends not only on algorithms, but also on mechanical structure, sensor placement, coordinate calibration, communication latency, and chassis-control accuracy.

The initial shopping-cart prototype provided practical experience in hardware integration. The final experimental platform made it possible to separate hardware uncertainty from algorithm performance and complete repeatable system-level validation.
