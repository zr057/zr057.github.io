FollowMe Autonomous Shopping Cart

A physical indoor mobile-robot prototype integrating LiDAR mapping, global-local path planning, obstacle avoidance, and differential-drive trajectory control for smart-retail scenarios.

View GitHub repository

Project outcome

The team converted a folding shopping cart into a mobile-robot prototype and evaluated indoor mapping, repeat localization, target following, path tracking, and corridor obstacle avoidance.

  • Built and integrated a differential-drive shopping-cart prototype.
  • Created a LiDAR-based indoor occupancy map for navigation.
  • Implemented grid-based global planning and local obstacle avoidance.
  • Connected planning output with closed-loop chassis control.

Reported results

1.59 mmean following distance
< 0.15 mpath-tracking error
±5°heading repeatability

Additional repeat-localization errors: X ±0.05 m and Y ±0.10 m. Values are taken from the formal final report.

System workflow

From environment sensing to chassis motion

The navigation pipeline connects perception, mapping, planning, and control in a closed physical loop.

01

Sense

LiDAR and odometry capture the surrounding geometry and robot state.

02

Map and localize

SLAM builds a two-dimensional occupancy map and estimates robot pose.

03

Plan

A* generates the global route while local planning reacts to nearby obstacles.

04

Control

Closed-loop control converts path error into differential wheel commands.

Planning contribution

  • Eight-direction grid search with map-boundary and collision checks
  • Heuristic-guided node expansion and parent-based path reconstruction
  • Redundant-turn removal and collision-checked path shortcutting
  • Local trajectory scoring using goal direction, obstacle clearance, speed, and global-route consistency

Evidence boundary

The formal report indicates that the laser-based navigation chain was the primary implemented system. Visual target recognition and multimodal fusion were not fully integrated.

The public repository contains a transparent reconstruction of the planning logic rather than the missing historical ROS workspace.
