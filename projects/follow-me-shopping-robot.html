Mobile robotics · Planning and control

FollowMe Autonomous Shopping Cart

A two-stage indoor robotics project: the team first modified a green folding shopping cart, then transferred navigation, obstacle avoidance, and motion-control testing to a four-wheel mobile platform.

View GitHub repository

Project outcome

The project began with the electric and sensor modification of a green folding shopping cart. The team later adopted a four-wheel mobile platform to evaluate path planning, trajectory tracking, and corridor obstacle avoidance.

  • Built and integrated a differential-drive shopping-cart prototype.
  • Integrated LiDAR hardware and prepared occupancy-grid inputs for planning.
  • Implemented grid-based global planning and local obstacle avoidance.
  • Connected planning output with closed-loop chassis control.

Reported results

1.59 mmean following distance
< 0.15 mpath-tracking error
±5°heading repeatability

Additional repeat-localization errors: X ±0.05 m and Y ±0.10 m. Values are taken from the formal final report; repeat counts and target-distance tolerance were not available in the public project materials.

System workflow

From environment representation to chassis motion

The verified planning workflow connects sensor inputs, occupancy-grid representation, global-local planning, and closed-loop control.

01

Sense

LiDAR and odometry capture the surrounding geometry and robot state.

02

Represent

A binary occupancy grid marks free space and obstacles for route generation.

03

Plan

A* generates the global route while local planning reacts to nearby obstacles.

04

Control

Closed-loop control converts path error into differential wheel commands.

Planning contribution

  • Eight-direction grid search with map-boundary and collision checks
  • Heuristic-guided node expansion and parent-based path reconstruction
  • Redundant-turn removal and collision-checked path shortcutting
  • Local trajectory scoring using goal direction, obstacle clearance, speed, and global-route consistency
