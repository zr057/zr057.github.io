Project overview

One technical route, developed across two platforms

The project began with a conventional green folding cart. It served as the physical prototype for motorized drive installation, LiDAR placement, embedded control, onboard computing, and ROS communication.

The final Ackermann platform provided a repeatable base for deploying the complete software chain. The research focus remained the same throughout: connect perception, target positioning, path planning, obstacle avoidance, and chassis control into a working follow-me system.

Planning algorithms

Global efficiency and local responsiveness

A* supplied global key nodes; DWA evaluated local, collision-free trajectories while remaining consistent with the global route.

Improved A* global planning

The team introduced target-oriented direction screening, obstacle-density-based heuristic adjustment, and two-stage redundant-node removal. These changes reduced unnecessary exploration and generated smoother routes with fewer turns.

  • Direction screening retained five target-oriented search directions.
  • Obstacle density adjusted the heuristic contribution.
  • Collinear-node removal and collision-checked shortcutting simplified the route.

Improved DWA local planning

The team added a target-distance term and dynamically adjusted obstacle-avoidance weights. Open space favored efficient forward motion; obstacle proximity increased the emphasis on safety and clearance.

Autonomous following

From target position to motion command

Two vehicle-mounted UWB base stations received signals from one target-worn tag. AoA supplied relative bearing, ranging supplied distance, and the front/rear receiver strategy extended directional coverage around the robot. LiDAR-based local planning remained active for unexpected obstacles.

01

Acquire & filter

Match the tag, solve bearing and distance, then smooth the target state with variable-step Kalman filtering.

02

Check safety

Compare the following distance with the safety threshold before generating motion commands.

03

Select direction

Follow directly when the target is ahead; when it moves behind, turn until it returns to the forward field.

04

Follow & avoid

Fuse the target command with global navigation and LiDAR-based local obstacle avoidance.

Physical validation

Localization, navigation, following, and avoidance

The final evaluation combined repeated measurements with physical indoor experiments.

UWB trajectory filtering

Three walking routes were tested three times each, producing nine measured target trajectories.

  • MSE: 0.0143 m²
  • MAE: 0.0938 m
  • Maximum deviation: 0.2847 m
  • Trajectory roughness: 0.0384 → 0.0100 m

Repeated navigation

The robot completed ten navigation trials between fixed start and target positions.

  • Travel-distance error: 0.15 ± 0.07%
  • Mean lateral offset: 0.012 ± 0.012 m
  • Mean heading deviation: 1.9 ± 1.0°
  • Heading fluctuation: 1.7 ± 0.4°

Target following

The robot followed a moving target along a route containing straight and turning segments. The mean following distance was 1.39 m, within the intended 1.0–1.5 m interval. Temporary fluctuations appeared during turns, after which the system returned to a stable following state.

Dynamic obstacle avoidance

A pedestrian entered the planned route while static obstacles remained present. The robot generated a collision-free detour, maintained target tracking, and continued the following task after passing the obstacle.

Engineering lessons

Algorithms depend on the complete system

The project demonstrated that autonomous robot performance depends not only on algorithms, but also on mechanical structure, sensor placement, coordinate calibration, communication latency, and chassis-control accuracy.

The green-cart prototype provided practical experience in drive conversion, sensor placement, and onboard integration. The final experimental platform then enabled repeatable, system-level validation of the same technical route.
